## Full description

Most creator workflows lose context between research, AI ideation, script writing, and thumbnail creation. I built YouTube Pro to keep that context connected.

In this five-minute walkthrough, I show how one topic becomes:

- A public YouTube Data API snapshot with up to 50 returned videos
- Inspectable analytics and source-video coverage
- AI Insights separated into observed findings, inference, and questions requiring YouTube Studio
- Grounded idea packages tied to the active research snapshot
- An editable script with a built-in teleprompter
- A minimal thumbnail brief and Gemini image workflow
- A restorable browser-local project

YouTube Pro does not access private YouTube Analytics, predict the algorithm, or guarantee performance. It is designed to make public evidence and AI interpretation easier to inspect before a creator makes the final decision.

The project is currently private while licensing and release review are completed. Subscribe for the public-release walkthrough and comment with the niche you want me to test next.

Independent project, not affiliated with or endorsed by YouTube or Google.
